macOS 自带的窗口管理能用，但和 Windows 的习惯不一样。Windows 用户习惯把窗口拖到屏幕边缘直接分屏，也习惯悬停任务栏看窗口预览；Mac 上这些动作要么没有，要么需要额外的快捷键。

Wins 补的就是这部分。它是一款 macOS 窗口管理工具，当前版本 3.6，支持拖拽分屏、悬浮分屏岛、Dock 窗口预览和 Cmd-Tab Plus。

## Wins 是什么？

Wins 是一款面向 macOS 的窗口管理工具。它把常见的窗口操作集中到几个入口：

- 拖动窗口到屏幕边缘
- 拖动窗口时出现悬浮分屏岛
- 悬停 Dock 图标预览窗口
- 用 Cmd-Tab Plus 切换具体窗口
- 用快捷键调整、隐藏或移动窗口

它没有独立主窗口，不占用菜单栏和 Dock，设置面板集成在 macOS 系统设置里。

## 核心功能

### 窗口快捷分屏

把任意窗口拖到屏幕边缘，可以选择全屏、半屏、四分之一等布局。对经常并排看文档、代码和浏览器的人来说，这比手动调整窗口大小快得多。

### 悬浮分屏岛

拖动窗口时，Wins 会显示悬浮分屏岛。把窗口拖到岛上的不同区域，可以快速组合布局。这个交互比记住一堆快捷键更直观。

### Cmd-Tab Plus

系统自带的 Cmd-Tab 只在应用之间切换。Cmd-Tab Plus 可以预览和切换同一个应用的不同窗口，也支持方向键、关闭窗口和退出应用。

对同时开多个浏览器窗口、编辑器窗口或 Finder 窗口的人来说，这个功能更接近 Windows 的任务切换体验。

### Dock 窗口预览

鼠标悬停在 Dock 图标上，可以预览该应用的所有窗口。它还支持 Dock 窗口反转：再次点击 Dock 图标，自动最小化对应窗口。

### 调度中心增强

在调度中心里可以快速关闭窗口，也可以使用 `Command + W` 关闭窗口、`Command + Q` 退出应用。这部分部分功能标注为 Pro。

### Aero Shake 与隐藏全部

左右摇动窗口可以隐藏其他窗口，也可以一键隐藏全部窗口。对临时需要清空桌面、专注当前任务的人很有用。

### 多显示器移动

Wins 支持把窗口快速移动到其他显示器，并提供动画效果。多屏用户可以少做几次拖拽。

### 系统级集成

Wins 没有菜单栏图标，也没有 Dock 图标，设置面板在系统设置中。它提供深色模式，界面风格跟随 macOS。

## 有哪些限制？

Wins 目前只支持 macOS，没有 Windows 版本。

免费试用只有 1 天，时间比较短。如果你需要更长时间判断，建议先集中测试自己最常用的几个动作：边缘分屏、Dock 预览、Cmd-Tab Plus 和多显示器移动。

部分功能标注为 Pro，购买前需要确认自己需要的功能是否包含在所选版本里。

它也不改变 macOS 本身的窗口系统，而是增强现有操作。如果你只需要偶尔分屏，系统自带功能可能已经够用。

## 适合谁？

更适合：

- 从 Windows 转到 Mac，想找回边缘分屏和任务栏预览的人
- 经常同时开很多窗口的人
- 希望用快捷键完成窗口布局的人
- 多显示器用户
- 不想让工具占用菜单栏或 Dock 的人

不太适合：

- 只需要偶尔分屏的人
- 使用 Windows 的人
- 不愿意为窗口管理单独付费的人
- 需要更长时间免费试用的人

## 最后判断

Wins 的定位很清楚：把 Windows 用户熟悉的窗口操作补到 Mac 上，同时保留 macOS 的系统集成和视觉风格。

如果你每天都在多个窗口之间切换，Wins 的 Dock 预览、Cmd-Tab Plus 和边缘分屏会比系统自带功能省事。如果你只是偶尔把两个窗口并排，系统功能已经够用。
