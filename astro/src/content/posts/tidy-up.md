Tidy Up 是一款 Mac 重复文件查找工具，由 Hyperbolic Software 开发。这家公司从 1996 年的 Doublet Scan 开始做重复文件检测，Tidy Up 是目前的主力产品。

它不清理缓存，也不做系统维护，只做一件事：找出重复的文件和项目，交给你决定删哪些。

## Tidy Up 是什么？

Tidy Up 的核心是搜索。选定要扫描的位置后，它会比对文件内容，把重复的条目列出来，按类型分组展示。

能扫描的范围包括：

- 本机硬盘和外接硬盘
- 指定文件夹
- Photos、Music、Mail、Lightroom、Contacts 的资料库
- iPhoto、Aperture 的旧资料库（Tidy Up 5 支持）
- Time Machine 的备份（需要安装管理员权限的辅助工具）

当前版本是 Tidy Up 6（6.0.10），要求 macOS 11.0 或更高，原生支持 Apple 芯片和 Intel。官网另有 Tidy Up 5（5.4.8），适用于 macOS 10.12 到 10.15。

## 简单模式和高级模式

Tidy Up 提供两种搜索方式。

**简单模式**内置 80 多个预设搜索，覆盖常见场景：重复图片、重复音乐、重复 PDF、按 EXIF 找照片、清理备份等。选中来源后点 Search 就开始扫描，不需要设置参数。

**高级模式**面向需要精确控制的用户，可以设置：

- 搜索哪些文件类型
- 目录优先级
- 创建时间和修改时间
- 是否包含硬链接
- 按名称、大小、内容中的哪些条件判断重复

如果你是第一次用，建议先从简单模式跑一遍，看清结果再决定要不要用高级模式。

## 扫描结果怎么看？

扫描结束后，Tidy Up 会给出总量和分类统计，包括检查的项目数、找到的重复项、可释放的空间，以及按文档、图片、压缩包、影片、音乐等类别的占用分布。

![Tidy Up 的扫描结果概览，按文件类型统计可释放空间](/media/tidy-up/results.png)

结果窗口可以切换网格或列表视图，每一类单独分页。判断哪些该删时，可以查看每项的元数据：创建时间、大小、所在路径。

对照片这类容易误删的内容，比较创建时间和拍摄信息比只看文件名可靠。

## Smart Boxes 是什么？

Smart Boxes 是 Tidy Up 比较独特的功能。它可以把同一个应用内部的重复项按相册、播放列表、邮箱等维度分组。

例如：

- Photos 里两个相册存了同一批照片
- Music 里同一首歌出现在不同播放列表
- Mail 里同一封邮件存在多个邮箱目录

普通查重只能看到「这两个文件内容相同」，Smart Boxes 能告诉你「它们分别属于哪个相册或播放列表」，判断保留哪一份更容易。

## 找到之后怎么处理？

Tidy Up 提供四种处理方式：

- 删除到废纸篓
- 用硬链接替换
- 用符号链接或别名替换
- 移动或复制到指定文件夹

硬链接是它比较实用的功能：重复文件被替换成指向同一份数据的链接，原路径仍然可用，磁盘只存一份内容。适合照片库、素材库这类目录结构不能乱的项目。

删除的项目会进废纸篓，可以恢复。搜索结果也能保存，下次继续处理没删完的部分。

## 和系统自带、其他清理软件的区别

- **访达的「查找重复文件」**：只能按名称判断，不看内容，遇到改名或复制粘贴的副本就失效
- **Mole、Sensei 这类清理工具**：以缓存、日志、卸载残留为主，查重只是附带功能
- **dupeGuru（免费）**：查重够用，但不深入 Photos、Music 这类应用的资料库，也没有 Smart Boxes
- **Tidy Up**：专注查重，能进资料库内部比较，处理方式更多

如果你只是偶尔清理一次下载文件夹，免费工具就够。如果你的照片、音乐、文档分散在多个库和多个硬盘里，Tidy Up 的深度搜索才有意义。

## 有哪些限制？

- 只做重复文件查找，不做缓存清理、卸载和系统优化
- 需要 macOS 11 或更高版本（Tidy Up 6）
- 界面语言为英文
- 清理 Time Machine 备份需要安装管理员级别的辅助工具
- 判断哪些该删仍要自己看元数据，软件不会替你决定
- 扫描大量文件时耗时较长，属于正常现象
- App Store 版本与官网授权不通用

## 适合谁？

更适合：

- 硬盘里堆了多年照片、音乐和文档的人
- 需要清理 Photos、Music、Lightroom 资料库的人
- 想用硬链接替换重复项、保留目录结构的人
- 要处理旧 Time Machine 备份的深度用户
- 需要使用外接硬盘、多块盘之间查重的人

不太适合：

- 只想清理缓存和系统垃圾的人
- 使用 macOS 10.15 及更早系统、又不打算买 Tidy Up 5 的人
- 需要中文界面的人
- 期待「一键清理、不用判断」的人

## 最后判断

Tidy Up 的定位很窄：重复文件查找。它把这个范围内的事情做得比较彻底——能进资料库内部比较，能按相册和播放列表分组，能用硬链接替换而不是直接删。

代价是它不能替代清理工具，也不适合「一键搞定」的使用习惯。如果你愿意花时间看结果、逐项确认，它能处理掉那些散落在多个资料库里的重复内容；如果你要的是省事，系统自带功能和免费工具已经够用。
