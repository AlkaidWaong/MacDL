Frame0 是一款手绘风格线框图工具，由 MKLabs 开发，用于把产品想法快速画成可以讨论的草图。它支持 macOS、Windows 和 Linux，文件保存在本机，可以离线使用。

它和 Figma、Sketch 的定位不同：Frame0 不追求精致，追求画得快。手绘外观本身也在传递一个信息——这是草稿，不用现在讨论配色和间距。

## Frame0 是什么？

Frame0 是一款本地运行的线框图应用，主要用来画四类内容：

- 界面线框图：网页、桌面、手机、平板、手表、电视
- 流程图和用户流程
- UML 图，包括用例图和类图
- ERD 实体关系图

界面上是画布加组件面板。拖入组件、连线、调整尺寸，就能组成一张草图。组件统一使用手绘风格，不需要自己调样式。

## 免费版能用哪些功能？

官网定价页把免费版写成 0 美元、没有时间限制，包含：

- 全部非高级功能
- 全部内置形状
- 全部 1500 多个图标
- 不限时间和文件大小

免费版和付费版的差别集中在三处：导出是否带水印、能否使用组件库和模板、能否把原型发布成 HTML 或 PDF。

数码荔枝的商品页也标注了「有限功能买前试用」，可以先下载免费版验证流程，再决定是否购买。

## 手绘风格解决什么问题？

手绘外观会降低两件事的期待值：

第一，画的人不会花时间对齐像素、挑颜色、调阴影，因为风格本身不允许精致。

第二，看的人不会把草图当成最终设计。官网的说法是，这种风格会让对方知道这是原型而不是成品，更容易提结构性的意见，而不是提前讨论视觉细节。

如果团队已经在 Figma 里反复改草稿，Frame0 省下的主要是这部分时间。

## 组件和状态

Frame0 内置桌面、手机、手表和网页的组件：按钮、表单、导航栏、卡片、弹窗、数据图表等。

不少组件带有可切换状态，例如开关的开与关、进度条的数值。画一套交互流程时，可以直接在画布上表现状态变化，不用为每个状态重画一遍。

![Frame0 内置手绘风格组件与状态](/media/frame0/components.webp)

## 图标

Frame0 把 Lucide 图标库转成了手绘风格，共 1500 多个，覆盖常用分类。图标和组件的线条风格一致，混用时不会出现一半精致一半草稿的情况。

## 流程图、UML 和 ERD

除了界面，Frame0 还能在同一个文件里画：

- 流程图
- UML 用例图
- UML 类图
- 实体关系图（ERD）

这部分用于画用户流程、信息架构和数据模型。官网把这类图表列为高级功能，需要 Solo 及以上授权。

![Frame0 中绘制的 UML 与 ERD 图](/media/frame0/image-1.webp)

## 镜像框架怎么用？

镜像（Mirroring）可以先做一个母版框架，再把它复用到多个页面。修改母版时，所有镜像同步更新。

适合页头、导航栏、底部栏这类重复出现的结构。改一次导航，所有页面一起变。

这个功能在官网上标注为实验性（Experimental），使用时建议先在副本上验证效果。

## AI Agent 和 MCP 怎么接？

Frame0 内置 AI Agent，可以通过对话生成线框图，也能把线框图转成代码。

它不额外收费，但要填入自己的 API Key，按服务商用量计费。可选的模型来自 OpenAI、Anthropic、Google Gemini 和 Grok。

如果不想配置 API Key，可以改用 Frame0 MCP Server，在 Claude Desktop、Cursor 等支持 MCP 的工具里调用 Frame0，由外部 AI 生成线框图。

这两种方式的共同点是：AI 生成的内容仍然在本地画布里，可以继续手动修改。

## 页面链接和演示模式

每个形状可以链接到另一个页面，形成一个可点击的流程。演示模式会把整个项目按幻灯片播放，点击画布上的元素就能跳到下一页。

向同事或客户讲流程时，比一张张切图更直接。这部分属于高级功能。

## 导出和发布

导出格式包括 PNG、SVG、JPEG 和 WebP。

付费版还能把原型发布成单个 HTML 文件或 PDF。HTML 保留交互，对方不用安装 Frame0，用浏览器或手机就能点着看。PDF 适合放进邮件或文档。

免费版导出带水印，付费后去掉。

## 支持哪些系统和平台？

官网下载页写明的要求：

- macOS 15 或更高版本，提供 Apple 芯片和 Intel 两个版本
- Windows 10 或更高版本，x86 版本
- Linux：Ubuntu 22.04、Fedora 40 或更高版本，提供 deb 和 rpm

官网首页还在标题旁标注了 Beta。

## 价格和授权

官网定价：

- Free：0 美元，无时间限制
- Solo：99 美元，1 台设备
- Duo：159 美元，2 台设备
- Team：79 美元/台，3 台起

都是一次买断，按设备数计费，永久使用，价格不含增值税。免费更新覆盖子版本，跨大版本升级是否收费以官方说明为准。

激活方式：打开 Frame0，点击左上角 `≡ > Help > License activation...`，粘贴激活码后点击 Activate。更换设备需要手动重置授权。

数码荔枝也销售 Frame0，中国区价格和发票、支付方式以商品页为准。

## 和 Balsamiq、Figma 有什么区别？

Balsamiq 是最接近的参照物。Frame0 官网用户评价里，不止一个人把它当作 Balsamiq 的替代：Nathan Day 说他在找 Balsamiq 替代品时发现了 Frame0，Jun Han 说它让人想起早期的 Balsamiq Mockups，Matt Cram 的形容是「像 Balsamiq 跟 Figma 学了几招」。

和 Figma 的差别在用途。Figma 覆盖从线框到最终设计、组件系统和交付的完整流程；Frame0 只做前半段，且默认你不需要后半段的精度。

和 Excalidraw 相比，Frame0 的组件更接近真实界面结构，带状态和模板，更适合画产品界面而不只是示意图。

## 有哪些限制？

- 不做最终视觉设计和像素级交付，交付物仍是草图
- macOS 需要 15 或更高版本，旧系统装不上
- 免费版导出带水印，去掉水印要购买
- 授权按设备数计算，换机需要手动重置
- AI Agent 需要自备 API Key，费用由模型服务商收取
- 官网没有列出实时多人协作功能，团队协作仍以文件传递和演示为主
- 镜像框架标注为实验性，复杂项目先在副本上验证效果
- 官网仍标注 Beta

## 适合谁？

更适合：

- 产品经理、设计师、工程师在方案阶段快速出图
- 需要向非设计背景的同事解释流程的人
- 要画流程图、UML、ERD，又不想再开一个工具的人
- 希望文件放本地、可以离线工作的人

不太适合：

- 需要输出高保真视觉稿和设计规范的人
- 依赖多人实时协作编辑的团队
- 使用 macOS 14 或更早系统的用户
- 只需要偶尔画一个方框、不想安装应用的人

## 最后判断

Frame0 把「画得快」放在第一位。手绘风格、组件状态、镜像框架、AI Agent 和 HTML 原型导出，都围绕快速沟通这件事。

免费版足够验证它是否适合你的工作方式：不限时间，可以画完整草图，只是导出带水印。如果线框图会经常出现在你的交付流程里，Solo 99 美元买断主要买的是无浮水印导出、组件库、模板和可交互原型。
