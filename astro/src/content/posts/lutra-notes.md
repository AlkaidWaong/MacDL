Lutra 是一款 Mac Markdown 编辑器，界面接近 macOS 自带的备忘录。它能从模板新建笔记，写完的内容以 `.md` 文件留在你选的文件夹里。

## 编辑体验接近 macOS 原生备忘录

左侧是文件夹和笔记列表，中间是正文，右侧可以查看文档大纲。打开一篇长笔记时，可以从大纲找到想继续写的章节。常用的格式、待办、表格和附件都能从顶部工具栏插入。

编辑器默认隐藏 Markdown 标记，标题和列表直接显示排版后的样子。这是 Lutra 写起来像系统备忘录的地方。需要检查原始语法时，可以在设置里切换标记的显示方式。[Lutra 官网](https://lutranotes.com/)

## 模板适合复用固定的笔记结构

「模板」在侧栏有独立入口。比如每周都要写复盘，可以把「本周进展」「遇到的问题」「下周安排」存成一份模板。下一次用它新建笔记，直接从第一个栏目开始写。日记和会议纪要也可以各留一份模板，集中在侧栏管理。[Lutra 官网](https://lutranotes.com/)

## 笔记保存在本地文件夹

正文以 Markdown 文件保存，插入的图片和 PDF 也留在同一个笔记文件夹里。平时可以在 Lutra 里按文件夹找笔记，需要交给别人或换编辑器时，可以直接找到原文件。对已经用文件夹整理项目资料的人，这比重新导出一遍方便。[Lutra 官网](https://lutranotes.com/)

## 可以改进的地方

- **在正文用 `/` 调用操作。** 写到一半需要插入待办或表格时，希望能输入 `/` 呼出菜单，再用键盘选中操作。已有的模板也可以考虑放进菜单，方便往当前笔记里插入一段固定结构。
- **让深色模式更适合长时间阅读和写作。** 默认的蓝绿色底色呼应应用图标，但铺满编辑区时有些抢眼。打开设置后，深灰背景和背后的蓝绿色编辑区差别明显。可以让两处采用更接近的中性底色，把蓝绿色留给按钮和选中状态。
