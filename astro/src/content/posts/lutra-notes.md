Lutra 是一款 Mac Markdown 编辑器。它把笔记保存为本地文件夹里的 Markdown 文件，同一份笔记也能用其他文本编辑器打开。测试版支持 macOS 15 或更新版本，目前可免费下载。开发者计划在正式版采用买断制。[Lutra 官网](https://lutranotes.com/)

## 编辑体验接近 macOS 原生备忘录

Lutra 的界面简洁，打开笔记就能接着写，整体感觉接近 macOS 自带的备忘录。编辑器默认隐藏 Markdown 标记，标题和列表会直接显示格式。需要看标记时，可以在设置里切换。[编辑器演示](https://lutranotes.com/)

## 模板适合复用固定的笔记结构

Lutra 有专门的模板管理。经常写会议纪要、周报或项目记录时，可以把固定的标题和栏目做成模板。下一次新建笔记时直接套用，再补当天的内容。

## 希望加入 `/` 快捷操作

写到一半需要插入待办列表、表格或代码块时，希望可以直接在正文输入 `/`，调出操作菜单，再用键盘选中要插入的内容。这样手可以留在键盘上，也少记几组语法。模板也适合从这里调用，尤其是需要在已有笔记里插入一段固定结构时。

## 深色模式的背景需要统一

默认深色模式的底色接近应用图标的色调，放在一起有一致的视觉风格。长时间阅读或写作时，这套配色的观感一般。设置页和 Markdown 编辑区也用了不同的背景色，从设置返回正文时，能感觉到色调的变化。

希望设置页和编辑区能用同一套中性底色，让正文、代码块和分隔线各自保持清楚。图标的颜色可以保留在按钮或选中状态上。

如果你习惯用原生备忘录随手写，又希望笔记以 Markdown 文件保存在本地，Lutra 值得一试。经常写同一种结构的内容，可以先建一个模板试几次。主要在深色模式下长时间写作的话，建议先用自己的长文试一下阅读观感。[下载 Lutra 测试版](https://lutranotes.com/)
