Anthropic 已完成 IPO 定价，并计划以 `ANT` 代码在纳斯达克开始交易。公司在 2026 年 11 月 18 日将首次公开发行定价为每股 83 美元，发行 980,000,000 股 A 类普通股。

这条消息值得科技用户关注，原因是 Anthropic 并不只做一个聊天产品。Claude 已进入桌面任务、编程、企业工具连接和 API 工作流。对 Mac 用户，最直接的产品是 Claude 桌面应用和 Claude Code。

阿里旗下蚂蚁集团与ANT 交易代码失之交臂，最后由 Anthropic 把它带上了纳斯达克。

## 先看 Anthropic 卖什么

| 产品或入口 | 用于什么 | 更接近谁 |
| --- | --- | --- |
| Claude | 对话、文件、研究、连接器和任务 | 个人与团队用户 |
| Claude Code | 读代码、修改文件、运行命令和处理 Git 工作流 | 开发者 |
| Claude Cowork | 使用桌面文件、工具和自动化完成更广泛的任务 | 知识工作者 |
| Claude Platform / Console | API 调用、模型接入和用量管理 | 开发者与企业 |
| Claude for Enterprise | 管理、权限、部署与组织能力 | 企业团队 |

Claude 是 Anthropic 面向用户的主要产品品牌。Claude Code、Claude Cowork 和 API 不同于普通聊天窗口，它们让 Claude 进入项目目录、文件夹、企业工具和开发流程。

因此，Anthropic 上市被关注，不只是因为一家 AI 公司增加了股票代码，也因为它正在把模型能力拆成更具体的工作产品。

## Anthropic 是什么公司

Anthropic 是一家 Public Benefit Corporation，简称 PBC。公司官网称，它开发可靠、可解释、可控制的前沿 AI 系统，并研究和降低这些系统带来的风险。

公司将工作分为四部分：

- **研究**：前沿 AI、可解释性、对齐以及 AI 的经济和社会影响
- **政策**：与政府和社会组织沟通前沿 AI 的影响
- **产品**：将研究转化为 Claude 等工具
- **运营**：招聘、法务、财务和组织运营

公司页面还列出董事会和 Long-Term Benefit Trust。Anthropic 说明，董事会由股东选举，Long-Term Benefit Trust 是其治理结构的一部分。

这些安排不直接决定 Claude 好不好用，但说明 Anthropic 对外介绍自己时，安全研究与产品部署处于同一层级。

## 这次上市确认了什么

| 日期 | 官方披露 |
| --- | --- |
| 2026 年 10 月 26 日 | Anthropic 提交 S-1 注册声明，计划以 `ANT` 在纳斯达克上市 |
| 2026 年 11 月 10 日 | 公司启动路演，拟发行 825,000,000 股，预计发行价为每股 70 至 78 美元 |
| 2026 年 11 月 18 日 | 公司将 IPO 定价为每股 83 美元，发行规模调整为 980,000,000 股 |
| 2026 年 11 月 19 日 | 官方公告称股票预计在这一天以 `ANT` 开始交易 |

定价公告写明，980,000,000 股中有 956,351,354 股由 Anthropic 出售，23,648,646 股由部分现有股东出售。公司不会从后者出售的股份中取得收益。

公告还给承销商一项 30 天选择权，最多可额外购买 147,000,000 股 A 类普通股。

官方公告没有使用“史上最大 IPO”的说法。它确认的是定价、发行股数、承销商选择权和预计交易日期。历史排名需要以统一口径比较其他发行项目。

本文不讨论股价、估值或买卖判断。

## Claude 为什么会从聊天窗口走到工作流

Claude 产品页将功能分为任务处理、连接器、文件与桌面访问、定时任务、Skills、插件和跨设备使用。

对用户而言，这意味着 Claude 的使用位置发生了变化：

| 原来的使用方式 | 现在的产品方向 |
| --- | --- |
| 在聊天窗口提问 | 将任务交给 Claude，并检查完成结果 |
| 手动复制文件和信息 | 连接文件、应用和数据源 |
| 单次生成内容 | 用 Projects、Skills、插件和定时任务保存重复流程 |
| 只在网页使用 | 在桌面、网页和移动端继续同一个任务 |

这些能力的可用范围取决于订阅、地区、组织设置和产品版本。实际使用时应以 Claude 账户界面和官方文档为准。

## Claude Code for Mac 在其中做什么

Claude Code 是 Anthropic 面向开发者的产品。它可以在 Mac 的终端、Claude 桌面应用、VS Code、JetBrains、网页和移动端入口中使用。

它可在本地项目中读取代码、修改文件、运行命令、执行测试，以及处理 Git 分支、提交和 Pull Request。

Mac 上有两种常用方式：

| 方式 | 适合的情况 |
| --- | --- |
| CLI | 已在终端、SSH、脚本或 CI 中工作 |
| Claude 桌面应用的 Code 标签页 | 希望选择项目、可视化查看 diff 和切换权限模式 |

CLI 支持 macOS 13.0 及更高版本。官方安装命令为：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

也可以使用 Homebrew：

```bash
brew install --cask claude-code
```

安装后，在项目目录运行：

```bash
claude
```

Claude 桌面应用提供 Apple Silicon 与 Intel Mac 的通用安装包。登录后打开 **Code** 标签页，选择项目目录即可开始会话。桌面应用包含 Claude Code，不需要单独安装 CLI。

## 费用和权限边界

Claude 免费计划不包含 Claude Code。官方定价页列出的个人套餐如下：

| 套餐 | 价格 | Claude Code |
| --- | --- | --- |
| Free | 0 美元 | 不包含 |
| Pro | 月付 20 美元，年付折合 17 美元/月 | 包含 |
| Max | 100 美元/月 | 包含 |
| Ultra | 200 美元/月 | 包含 |

也可以使用 Anthropic Console 按 API token 用量付费。套餐、用量限制和价格应以 [Claude 定价页](https://claude.com/pricing) 为准。

Claude Code 可以读文件、修改文件和运行命令。Manual 模式会在编辑或命令执行前请求确认，Plan 模式用于先阅读和规划，不修改源文件。

`bypassPermissions` 会跳过权限提示。官方建议只在容器或虚拟机等隔离环境中使用。

## Claude Code 与其他 Agent 工具

[OpenCode](/article/opencode-go) 是可直接执行编码任务的开源 Agent，可连接免费模型和其他提供商。

[T3 Code](/article/t3-code) 可集中管理 Claude Code、Codex、OpenCode 等已安装 Agent 的线程和 Git 操作。

[Orca ADE](/article/orca-ade) 可为并行 Agent 任务建立独立 Git worktree，便于比较差异和合并代码。

三款工具的执行、调度和隔离分工见 [OpenCode、T3 Code 与 Orca ADE 横评](/article/opencode-t3-code-orca-comparison)。

## 常见问题

### Anthropic 已经在纳斯达克交易了吗

Anthropic 的官方定价公告称，股票预计于 2026 年 11 月 19 日以 `ANT` 在纳斯达克 Global Select Market 开始交易。应通过纳斯达克和券商的实时市场数据确认具体交易状态。

### Anthropic 和 Claude 是什么关系

Anthropic 是公司，Claude 是其产品品牌。Claude Code、Claude Cowork、Claude Platform 和 Claude for Enterprise 都是围绕 Claude 的不同产品或入口。

### Claude Code for Mac 需要 Node.js 吗

Claude 桌面应用的 Code 标签页不需要 Node.js 或 CLI。使用 npm 安装 Claude Code CLI 时，官方文档要求 Node.js 22 或更高版本。

### Claude Code 能替代编辑器吗

Claude Code 可以在项目中修改文件和运行开发工具，但完整的代码浏览、调试器和编辑器扩展仍由 VS Code、Zed、Cursor 或其他编辑器提供。
