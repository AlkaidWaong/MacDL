Mac 高负载时，风扇转速和温度会直接影响使用体验。机器太热会降频，风扇太吵又影响工作。

Macs Fan Control 用来查看这些状态，并在需要时接管风扇转速。它支持 Intel Mac 和 Apple Silicon Mac，当前版本为 1.5.23，要求 macOS 10.13 或更高版本。

## Macs Fan Control 是什么？

Macs Fan Control 是一款 macOS 风扇控制与温度监控工具。主界面分为两部分：

- 左侧是风扇列表，显示最小、当前和最大 RPM
- 右侧是温度传感器列表，显示各部件当前温度

每个风扇可以在 Auto、Full blast 和 Custom 之间切换。Custom 可以设定固定 RPM，也可以按某个温度传感器联动。

应用退出时，会自动把所有风扇恢复为 Auto，由系统重新接管。

## 它解决什么问题？

### 高负载时提前提高散热

MacBook Pro 或 iMac 在视频导出、编译、游戏或长时间会议时可能温度升高。Macs Fan Control 可以让风扇更早进入高转速，或在温度达到设定值时自动加速。

### 降低特定场景的噪音

反过来，如果风扇在低负载时仍然偏吵，可以手动降低转速。但降低转速会让温度上升，需要同时观察传感器数据，不能只看噪音。

### 监控第三方硬盘温度

官网说明支持通过 S.M.A.R.T. 读取第三方 HDD/SSD 的温度。对更换过硬盘的 iMac 或外接存储用户，这个信息比系统自带工具更直接。

## 核心功能

### 实时监控

查看风扇当前 RPM、最小/最大范围，以及 CPU、GPU、硬盘等温度传感器。部分传感器是否可用取决于 Mac 机型。

### 自定义转速

在 Custom 模式下设置固定 RPM，或者选择一个温度传感器作为依据，让风扇按温度变化自动调整。

### 风扇预设

免费版提供三个预设：

- Automatic：全部交给系统
- Full blast：风扇全速
- Custom：手动控制

Pro 版可以创建和保存自定义预设，方便在办公、渲染、游戏等场景之间切换。

### 菜单栏显示

可以把风扇转速或传感器温度放到菜单栏，随时查看当前状态。

### Windows Boot Camp

官网还提供 Windows 版本，适用于通过 Boot Camp 安装的 Windows。Windows 版提供 14 天试用，需要对应的 Pro 授权。

## 免费版和 Pro 版怎么选？

免费版已经包含监控、Custom 模式和三个基础预设，适合偶尔查看温度、临时调转速的人。

Pro 版主要增加：

- 自定义风扇预设的创建和保存
- 优先客户支持
- 后续更新支持

Pro 授权按电脑数量计算，一次购买，没有订阅。具体价格和设备数、macOS/Windows 授权范围，以官网购买页为准。

## 怎么用？

1. 从官网下载并安装 Macs Fan Control。
2. 打开应用，查看风扇和温度传感器列表。
3. 保持 Auto 模式先观察一段时间，确认日常温度和转速。
4. 需要手动控制时，把对应风扇切到 Custom，设置 RPM 或温度联动。
5. 需要频繁切换场景时，创建预设；Pro 版可以保存多个自定义预设。
6. 退出应用后，风扇会自动回到 Auto。

如果你只需要监控，不需要接管风扇，可以让所有风扇保持 Auto，应用会以只读模式运行。

## 有哪些风险？

Macs Fan Control 官网把它定位为面向高级用户的工具。使用前需要了解：

- 风扇转速和温度与机型、系统版本有关，部分传感器可能不可用
- 长期把转速设得过低，可能导致温度升高和降频
- 长期把转速设得过高，会增加噪音和积灰
- 退出应用后风扇会恢复 Auto，不能把它当成永久硬件改造
- 高负载场景仍应优先改善散热环境，软件不能替代物理散热

如果只是为了看温度，保持 Auto 模式最安全。需要手动控制时，先小范围调整，观察温度和噪音，再决定是否长期使用。

## 适合谁？

更适合：

- Mac 经常高负载、温度偏高的人
- 想查看风扇转速和温度传感器的人
- 需要固定 RPM 或按温度联动的人
- 使用 Intel Mac 或 Apple Silicon Mac 的用户

不太适合：

- 只想偶尔看一下温度、不想调整设置的人
- 期待软件解决所有散热问题的人
- 不愿意观察温度变化、只想把风扇拉到最低的人
- 使用非 Boot Camp Windows 的人

## 最后判断

Macs Fan Control 的功能很集中：监控风扇和温度，允许用户在 Auto 与 Custom 之间切换，并在退出时恢复系统控制。

免费版适合先观察和临时调整；如果你需要保存多套风扇预设，或者需要 Windows Boot Camp 支持，再考虑 Pro。
