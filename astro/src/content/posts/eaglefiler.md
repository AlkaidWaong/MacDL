EagleFiler 是一款 Mac 文件归档工具，由 C-Command Software 开发，当前版本 1.9.22，发布于 2026 年 10 月。

它解决的问题是「资料散落在浏览器、邮件客户端和下载文件夹里，想找的时候找不到」。做法是建一个库，把东西收进去，再提供搜索、标签和智能文件夹。

## EagleFiler 是什么？

EagleFiler 的库是一个普通的文件夹结构，不是专有数据库。

这意味着两件事：

- 文件保持原本格式，PDF 还是 PDF，网页存档还是 Web Archive
- 在访达里可以直接打开、复制、备份，不依赖 EagleFiler 才能读

应用本身提供三层界面：左边是文件夹和标签，中间是文件列表，右边是内容预览。用起来接近邮件客户端。

![EagleFiler 的三栏界面，左侧文件夹与标签，右侧内容预览](/media/eaglefiler/hero.jpg)

## 怎么把资料收进来？

EagleFiler 的导入方式集中在几个快捷键：

- `F1`：导入当前网页、选中的邮件或访达里的文件
- `Option + F1`：导入时直接填写标题、标签、备注
- `Shift + F1`：新建一条快速笔记
- `Command + Shift + 1`：把任意应用里选中的文字存进库
- iPhone 拍照或扫描：直接从手机导入

网页可以存成 Web Archive、PDF 或 RTF，保留图片、排版和原始网址。也支持导入 Pinboard、Safari 的书签列表，以及归档 X（Twitter）的推文。

## 邮件归档

这是 EagleFiler 比较独特的一块。

- 支持 Apple Mail、Microsoft Outlook、.eml 等来源
- 统一转换成标准 mbox 格式
- 可以按邮箱、按年份归档，减轻邮件客户端的负担
- 也能用来给 IMAP 服务器做本地备份
- 支持清理重复邮件

对邮件量大、又不想一直把历史邮件留在客户端里的人来说，这比手动导出单个 .eml 实用。

## 搜索和智能文件夹

- **实时搜索**：官方称比 Spotlight 更快，会高亮匹配位置
- **搜索范围**：正文、附件内容、标签、备注都能搜
- **智能文件夹**：支持嵌套条件，比如「标签包含 draft」且「创建时间在某个区间」
- **智能文件夹动作**：满足条件时自动执行操作
- **Spotlight 集成**：库里的文件和标签也能被系统搜索到

智能文件夹的条件可以任意组合，适合把「未读 + 某个项目 + 最近三个月」这类筛选固定下来。

![EagleFiler 的智能文件夹条件，支持嵌套的任意/全部判断](/media/eaglefiler/smart-folder-conditions.png)

## 标签、备注和其他整理方式

- **标签**：与访达标签互通，额外支持层级和符号前缀
- **备注**：富文本，可以插入链接和附件
- **标记**：旗标、未读状态、彩色标签，都会同步到访达
- **直接编辑**：RTF、纯文本和 Markdown 文件可以在应用内改
- **多库**：可以建多个库，放在不同位置，同时打开并互相拖放文件
- **跳过重复**：导入时自动识别重复文件

标签用符号前缀是个小设计，比如给「人物」类标签统一加一个符号，列表里容易区分。

## 安全和数据完整性

- **AES 加密**：整个库加密，包括磁盘上的索引；输入密码后可以正常搜索
- **校验和**：用校验值验证文件是否损坏，防止位衰减
- **验证功能**：可以定期检查库里的文件完整性

对长期存档的资料，校验和比加密更实用：几年后打开，能知道文件有没有坏。

## 自动化和生态

- 支持 AppleScript，可以脚本化导入、搜索和整理
- 支持「文具脚本」，新建文档时自动套用模板
- 与 Alfred、LaunchBar、Hookmark、PopClip、ScanSnap 等工具配合

比如装 [PopClip](/article/popclip/) 之后，选中文字点一下就能存进 EagleFiler，不用切窗口。

## 和访达、DEVONthink、Obsidian 的区别

- **访达 + Spotlight**：免费，但搜索能力和标签管理有限，邮件归档基本做不了
- **DEVONthink**：功能更全，带 AI 分类和更强的数据库能力，价格也更高
- **Obsidian**：以 Markdown 笔记为中心，不适合存放大量原始文件和邮件
- **EagleFiler**：介于两者之间，保留原文件格式，提供搜索、标签和归档

如果你只是想给下载文件夹加个标签，访达够用。如果你有十几年的邮件、论文 PDF 和网页存档要找，EagleFiler 的定位才对得上。

## 有哪些限制？

- 界面以英文为主，没有中文界面
- 没有 iOS 版，手机端只能通过其他方式访问库
- 不提供云同步，需要自己把库放进 Dropbox 或 iCloud Drive
- 不支持多人协作
- 界面风格偏传统，不是现代笔记应用的设计
- 买断价格高于多数笔记工具
- Mac App Store 版本功能与官网版有差异，大版本升级优惠也不适用

## 适合谁？

更适合：

- 需要长期保存网页、邮件和 PDF 的人
- 做研究、写论文、要反复查资料的人
- 邮件太多、想从客户端里归档出来的人
- 希望资料结构开放、不被应用锁死的人
- 需要加密存储敏感资料的人

不太适合：

- 只需要记几条笔记的人
- 主要在 iPhone 或 iPad 上处理资料的人
- 需要团队共享和协作的场合
- 不愿意为归档工具付费的人

## 最后判断

EagleFiler 不是笔记应用，也不是云盘，它更像一个私人档案馆：东西原样存进去，用标签和搜索找出来。

它最值得买的部分是「不锁死」——库是普通文件夹，应用不在了资料还在。加上邮件归档、智能文件夹、校验和和加密，覆盖了长期存档需要的几件事。

69.99 美元不算便宜，但这是一次买断。如果你的资料已经多到靠访达和 Spotlight 管不过来，这个价格的替代品并不多；如果只是偶尔存几篇文章，系统自带的功能就够。
